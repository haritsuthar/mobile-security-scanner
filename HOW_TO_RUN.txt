================================================================
TROUBLESHOOTING
================================================================

Problem : "Cannot connect to MobSF" shown in scan results
Fix     : MobSF is not running. Start it using Terminal 1 command above.

Problem : Browser shows "This site can't be reached" on port 5000
Fix     : Flask is not running. Start it using Terminal 2 command above.

Problem : Static Analysis shows 500 error
Fix     : MobSF database needs migration. Run:
          cd "...Mobile-Security-Framework-MobSF"
          python -m poetry run python manage.py makemigrations StaticAnalyzer --no-input
          python -m poetry run python manage.py migrate --no-input
          python -m poetry run python manage.py create_roles

Problem : "poetry not found"
Fix     : Run:  python -m pip install poetry==1.8.4

Problem : npm ENOENT / package.json not found
Fix     : This project does not use npm in the MobSF folder.
      Use the Python/Poetry commands in STEP 1 and STEP 2 instead.

Problem : Java error in MobSF logs
Fix     : Java is at C:\jdk17\jdk-17.0.11+9\bin\
          Make sure C:\Users\Harit\.MobSF\config.py has:
          JAVA_DIRECTORY = 'C:/jdk17/jdk-17.0.11+9/bin/'

Problem : Port already in use
Fix     : Kill the process using the port:
          netstat -ano | findstr :5000
          taskkill /PID <pid> /F

  requirements.txt                <- Python dependencies
  templates/
    index.html                    <- Upload page
    result.html                   <- Scan results page
  uploads/                        <- Uploaded APK files (auto-created)
  reports/                        <- Generated JSON + PDF reports (auto-created)
  Mobile-Security-Framework-MobSF/  <- MobSF engine (static analysis backend)


================================================================
HOW IT WORKS
================================================================

1. You upload an APK via the Flask web interface (port 5000)
2. Flask sends the APK to MobSF via its REST API (port 8000)
3. MobSF performs static analysis:
   - Decompiles the APK using JADX
   - Checks permissions, manifest, code patterns
   - Calculates a security score (0-100)
4. Flask also scans the APK binary for:
   - Hardcoded HTTP endpoints (plaintext traffic risk)
   - Hardcoded IP addresses
5. Results are shown on screen and saved as JSON + PDF reports
