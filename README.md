# Mobile Security Scanner

## Features
- APK upload validation
- Static analysis with MobSF
- Dynamic analysis with Frida
- API testing support
- JSON report generation
- SHA256 hashing
- Improved UI

## Run Project

### Install Dependencies
pip install -r requirements.txt

### Start MobSF
Run MobSF locally on:
http://127.0.0.1:8000

### Run Flask App
python app.py

### Open Browser
http://127.0.0.1:5000
